SAI ANU FURNITURE - WEBSITE PREVIEW STARTER

CONTENTS
- index.html: customer-facing website preview
- images/: four sample sofa photos bundled locally

HOW TO TEST
1. Extract this ZIP.
2. Open index.html in a browser to preview the site.
3. To publish a static preview, upload the CONTENTS of this folder (index.html and images folder) to the root of your GitHub Pages repository.

IMPORTANT - NOT YET A SECURE LIVE ADMIN SYSTEM
This package is a front-end preview, not the finished production system.
- The current Admin section is a local browser demo; it is NOT protected by real private authentication.
- Uploaded product photos and demo requests are stored only in that browser/device. They do not sync to your customers' phones or a private owner dashboard.
- Customer enquiries are opened in WhatsApp; they are not automatically delivered to a shared database.
- The temporary password shared in chat is deliberately NOT included in this ZIP. Do not publish passwords in HTML or JavaScript.
- Do not use this preview for real customer records or publish it as a secure Admin system.

REQUIRED BEFORE PRODUCTION
Connect Firebase Authentication, Firestore and Storage (or another secure backend), configure owner-only Admin access and database/storage security rules, then connect product uploads, customer orders, repair requests and customer-uploaded sofa photos to that backend. GitHub Pages alone cannot provide these backend services.

PLANNED REQUIREMENTS TO COMPLETE
- Separate private Admin login and owner dashboard
- Admin category pages for Sofas, Beds, Dressing Tables, Almirahs, Dining Tables and Office Furniture
- Admin can add/edit/delete products, upload photos, set names/prices/colours and publish them
- Shared product catalogue visible to customers
- Repair/Cleaning form with sofa photo upload saved to Admin dashboard
- Customer order and request management
- Try at Home with room upload and sofa overlay/edit tools
- Mobile-friendly customer website and installable PWA; Android APK requires a separate Android build
